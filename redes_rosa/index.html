Arquitetura do sistema

TECHNICAL DOCUMENTATION

Docker: plataforma utilizada para executar aplicações em contêineres isolados, facilitando a implantação e o gerenciamento dos serviços.

Servidor Web: utiliza Nginx para disponibilizar a página HTML na porta 8181, redirecionada para a porta 80 do contêiner.

Servidor de arquivos: utiliza File Browser para permitir o envio, download, organização e gerenciamento de documentos pela interface Web na porta 8080.

Volumes: conectam os diretórios internos dos contêineres à máquina hospedeira, garantindo a persistência dos arquivos e configurações.

Autenticação: o File Browser permite cadastrar usuários e senhas, controlando o acesso aos documentos de acordo com as permissões.

Docker Compose: gerencia a configuração e a inicialização dos dois serviços, permitindo sua execução independente e simultânea.

Dessa maneira, a infraestrutura centraliza o armazenamento de arquivos, facilita o compartilhamento de informações e simplifica a administração dos serviços na rede local.
